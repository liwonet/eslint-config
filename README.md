It's an opinionated and aggressive eslint config.

## Install

```shell
pnpm add -D eslint @liwo/eslint-config
```

Add `package.json` scripts.

```json
{
  "scripts": {
    "lint": "eslint .",
    "format": "eslint --fix ."
  }
}
```

## Usage

```shell
pnpm run lint
```

```shell
pnpm run format
```
